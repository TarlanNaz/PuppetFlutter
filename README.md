# Puppet Forge (ЛР1 — Каркас)

Это каркасное кроссплатформенное приложение, разработанное на **Flutter** в рамках Лабораторной работы 1. Приложение представляет собой клиент для просмотра каталога модулей [Puppet Forge](https://forge.puppet.com/). 

Главная цель вехи — собрать устойчивый каркас, в котором корректно работают навигация, смена темы и языка, а экраны строятся на основе состояния.

## Реализованные требования (Критерии приёмки)

* **Моки данных по форме API:** Подготовлено 20 записей-моков, структура которых полностью повторяет ответ реального REST API (`forgeapi.puppet.com/v3/modules`). Сеть пока отключена, данные подгружаются локально.
* **Навигация:** Реализована с помощью современного пакета `go_router`. Настроен маршрут списка (`/`) и деталей (`/module/:slug`). Возврат назад работает нативно, а переход выглядит как `push` (слайд-анимация).
* **Темизация (Material 3):** Реализована через токены `ThemeData` и `ColorScheme.fromSeed`. В UI нет зашитых (hardcoded) цветов — всё опирается на семантические цвета темы. Поддерживается светлая и тёмная темы.
* **Локализация:** Поддерживаются два языка — Английский (en) и Русский (ru). Все подписи вынесены в файлы ресурсов `.arb`. Генерация кода осуществляется через `flutter_localizations` и `flutter_gen`.
* **Управление состоянием:** 
  * Глобальные настройки (тема и язык) живут в памяти сессии с помощью пакета `provider` (`AppSettings`). Экран не рассыпается при их смене.
  * Локальное состояние (строка поиска) работает через `StatefulWidget` — список фильтруется "на лету" без нарушения структуры приложения.

## Структура проекта

```text
lib/
├── data/
│   └── mock_modules.dart        # Замоканные данные
├── l10n/
│   ├── app_en.arb               # Английский словарь
│   └── app_ru.arb               # Русский словарь
├── models/
│   └── puppet_module.dart       # Data-класс, описывающий поля API
├── navigation/
│   └── app_router.dart          # Настройки GoRouter и переходов
├── screens/
│   ├── module_detail_screen.dart # Экран деталей модуля
│   └── module_list_screen.dart   # Главный экран (список + поиск)
├── theme/
│   ├── app_settings.dart        # Провайдер состояния темы и языка
│   └── app_theme.dart           # Настройки светлой и тёмной Material3 тем
└── main.dart                    # Точка входа, инициализация Provider и MaterialApp
```

## Как запустить

Убедитесь, что у вас установлен Flutter SDK версии `3.13` или выше.

1. Установите зависимости:
   ```bash
   flutter pub get
   ```

2. Сгенерируйте файлы локализации (если они не сгенерировались автоматически):
   ```bash
   flutter gen-l10n
   ```

3. Запустите проект (на подключенном девайсе, эмуляторе или десктопе):
   ```bash
   flutter run
   ```
